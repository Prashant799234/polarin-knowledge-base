The **Activity Log** gives you a complete audit trail of everything that happens across your Polarin organisation -- from service provisioning and billing updates to user logins and configuration changes. Every event is timestamped, attributed to a user, and tagged with a severity level so you can quickly spot issues or verify past actions.

New to this page? [Activity Log Overview](/settings/activity-logs/overview) covers why it exists and what it's for, before you dive into the details below.

## View the Activity Log

Follow these steps to open and browse your activity log:

<Steps>
  <Step title="Sign in">
    Go to **polarin.lightstorm.net** and sign in with your credentials.
  </Step>
  <Step title="Open Settings -> Activity Logs">
    Click **Settings** in the top navigation, then **Activity Logs** under the **Organisation** section of the left sidebar.
  </Step>
  <Step title="Browse events">
    The table lists every event with its **Activity ID**, **Services**, **Date & time**, **Event**, who it was **Initiated By**, and its **Severity** badge.

    ![Activity Log main table](/images/screenshots/activity-logs/01-activity-logs-table.jpg)

    - **1 -- Search by Activity ID**: Type or paste an exact Activity ID to locate a specific event instantly.
    - **2 -- Date Range Filter**: Select a custom Start Date and End Date using the dual-month calendar picker.
    - **3 -- Services Filter**: Filter by platform domain (Organisation Profile, Billing, Authentication, Ports, Cloud Connect connections, Virtual Routers).
    - **4 -- Date & Time Sort**: Click the column header to toggle between newest-first and oldest-first chronological sorting.
    - **5 -- Event & Initiated By**: See the specific operation (e.g., User Login, Billing Profile Created) and the user who triggered it.
    - **6 -- Severity Tag**: Colour-coded badge indicating the priority level from S0 (Emergency) to S7 (Debugging).
  </Step>
</Steps>

## Log Detail Panel

Click any row to open its full detail in a panel on the right -- including the network and device information behind that event.

![Activity Log detail panel](/images/screenshots/activity-log-details.png)

## Filter & Search

The Activity Log page gives you several ways to narrow down events, and you can combine them for precise results.

- **Search by Activity ID**: Type or paste an Activity ID to jump straight to that event.
- **Date range**: Pick a Start Date and End Date from the calendar, then click Apply to narrow results to that window.
- **Services**: Filter by service: Organisation Profile, Billing Profile, Authentication, Port, Cloud Connect, or Virtual Router.
- **Initiated By**: Filter by the user or system actor who triggered the event.
- **Severity**: Filter by one or more severity levels, from S0 (Emergency) to S7 (Debugging).
- **Sort by date & time**: Click the sort icon on the Date & time column to switch between newest-first and oldest-first.

![Date range filter with a dual-month calendar](/images/screenshots/activity-logs/02-date-filter.jpg)

- **1 -- Date Range Inputs**: Displays the active Start Date and End Date selection.
- **2 -- Dual-Month Calendar**: Browse across months with navigation chevrons and select a continuous range.
- **3 -- Apply Button**: Click Apply to instantly refresh the event table for the selected range.

<Tip>
  Combine the **Services** filter with a **date range** and **Severity** to quickly audit all errors affecting a specific service within a given period. To configure proactive notification rules instead of searching manually after an event, see [Manage Alerts](/vista/manage-alerts).
</Tip>

## Severity Levels

Every event is assigned a severity level from **S0 (Emergency)** to **S7 (Debugging)**. Use the Severity filter to select one or more levels and focus on what matters right now.

![Severity filter dropdown with all eight levels](/images/screenshots/activity-log-severity-filter.png)

| Level | Label | Description |
| --- | --- | --- |
| S0 | Emergency | Immediate attention required |
| S1 | Alert | Urgent action needed |
| S2 | Critical | Significant impact on operations |
| S3 | Error | Operational issue detected |
| S4 | Warning | Potential problem or anomaly |
| S5 | Notification | Routine status update |
| S6 | Info | General information event |
| S7 | Debugging | Diagnostic and trace information |

<Info>
  Not every severity level shows up in every organisation's log -- which ones you see depends on what's actually happened on your account. **S5 (Notification)** and **S6 (Info)** are the most common day-to-day events; **S0--S2** flag the events that need the fastest attention.
</Info>
