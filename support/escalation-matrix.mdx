## Incident Severity Classification

Escalation countdowns are measured from initial ticket logging based on whether an incident is classified as **Service Affecting** or **Non-Service Affecting**:

### Service Affecting (Critical / P1)

Direct customer traffic downtime, hard circuit failure, or active packet drop:

- Total physical port or Cloud Connect link down
- BGP peering dropped with no redundant route
- Sustained packet loss (>5%) or severe latency breach
- Failure of primary route on a protected path

**Trigger intervals:** 1h–3h (India) · 2h–8h (APAC)

### Non-Service Affecting (Standard / P2–P4)

Operational, reporting, or non-traffic-impacting inquiries:

- Secondary standby link flap (active traffic unaffected)
- Portal account access, API tokens, or user permissions
- Telemetry graphs, usage reports, or audit inquiries
- Scheduled maintenance queries and configuration requests

**Trigger intervals:** 2h–6h (India) · 4h–16h (APAC)

## Before You Escalate

To ensure our engineering teams can respond immediately, please keep the following identifiers ready:

1. **Incident / Ticket ID** — Active ticket reference (e.g. #INC-XXXXXX) logged with Level 1.
2. **Polarin Service ID** — Port ID (PORT-SIN-001) or Cloud Connect ID (VC-AWS-009).
3. **Location Details** — Originating and terminating data centres or cloud PoP regions.
4. **Observed Impact** — Telemetry details (loss, latency, flap frequency) and affected services.

<Tip>
  Always open a ticket first with **Level 1 GSOD** (+91-22-69315544 or [GSODesk@lightstorm.net](mailto:GSODesk@lightstorm.net)) or via [Create a Ticket](/support/create-ticket) so that diagnostic test bridges and timestamped telemetry logs are initiated immediately.
</Tip>
