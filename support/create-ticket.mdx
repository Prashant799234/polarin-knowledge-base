Raise a ticket when something needs Polarin's team to look into it directly — a service issue, a billing question specific to your account, or anything self-serve documentation can't answer. The more detail you give up front, the faster it gets resolved.

<Tip>
  Not sure this needs a ticket? Check [Get Support](/support/overview) first — most common questions are already answered in the Knowledge Base.
</Tip>

## Before You Start

- Make sure you're signed in — tickets are tied to your account so you (and your team) can track them.
- Know roughly which service is affected, if any — you can attach up to 4.
- Have any screenshots or files ready — you can attach one per submission, up to 10 MB.

## Create Your Ticket

<Steps>
  <Step title="Open Create a Ticket">
    Go to **Help → Create a Ticket** from the top navigation.
  </Step>
  <Step title="Select the affected service (optional)">
    Search and select up to 4 services this issue relates to. This step is optional — skip it for account or billing questions that aren't tied to a specific service.

    ![Selecting affected services when creating a ticket](/images/screenshots/create-ticket-select-services.png)

    Search and select up to 4 affected services, or leave this blank.
  </Step>
  <Step title="Choose an issue type and category">
    Pick **Technical Issues** (service functionality, performance, or connectivity problems) or **Non-Technical Issues** (account, billing, documentation, or general inquiries), then select the closest matching category.

    ![Selecting issue type and category](/images/screenshots/create-ticket-select-issue-type.png)

    Non-Technical categories include Billing, CAF / Order Form / PO, Letter of Authorization, and more.

    For Non-Technical issues, the available categories are:

    - Billing
    - CAF / Order Form / PO
    - Letter of Authorization
    - Promo Code / Offers
    - Provisioning
    - Purchase Order
    - Quote
    - Others
  </Step>
  <Step title="Describe the issue and attach files">
    Write a clear description — what happened, when it started, and what you expected instead. Attach a screenshot or log file if it helps explain the issue.
  </Step>
  <Step title="Submit">
    Submit the ticket. It gets a **Ticket ID** right away, and shows up immediately in [My Tickets](/support/my-tickets).
  </Step>
</Steps>

## Raising It From a Service

You don't always have to start from Help. Open any service's detail page — a Port, a Cloud Connect connection, a Virtual Router — and click **Raise a Ticket** right next to **Edit**. It's the faster path when you're already looking at the specific service having the issue.

![Raise a Ticket button on a service detail page](/images/screenshots/raise-ticket-from-service.png)

Every service's own page has a direct Raise a Ticket shortcut.
