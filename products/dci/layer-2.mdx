**DCI Layer 2** is an Ethernet-based interconnect between two of your ports — it's the form of [Data Centre Interconnect](/products/dci/overview) most teams reach for, since it rides on infrastructure you've likely already provisioned. For the optical, Layer-1 alternative built for the highest, most predictable throughput, see [Create a DCI Wave Connection](/products/dci/wave).

## Before You Begin

<Warning>
  You need an active [Port](/products/port/create) already provisioned at **both** the A-End and Z-End locations before starting this wizard — DCI Layer 2 connects two existing ports, it doesn't create them.
</Warning>

## 1. Port Selection

From **Services**, create a new **DCI Layer 2** connection. The wizard's progress trail shows four steps: **Port Selection → Configure Connection → Add Ons → Checkout**.

Select the **A-End Port** and **Z-End Port** from searchable lists of your existing ports. The diagram on the left updates live to show both ends and the link between them, along with a live availability percentage for the path.

## 2. Configure Connection

| Field | Description | Required |
| --- | --- | --- |
| Virtual Connection Name | Must be unique across your organisation. Alphanumeric characters and hyphens only. | Yes |
| MACSec Encryption | A toggle. When on, enables transparent tunnelling of encrypted traffic between your A-End and Z-End. Encryption and key management remain your responsibility at both ends — Polarin only carries the encrypted traffic. | No |
| Advanced Settings → Select VLAN Type | Tagged (default — a single VLAN ID is assigned; only traffic carrying that VLAN ID passes through, and you can keep using the same physical ports for other connections), Untagged, or Trunk. | No |
| VLAN ID (Optional) | Only shown for a Tagged connection. Leave blank and Polarin auto-allocates the next available ID — the form shows live suggestions (e.g. 453, 364) if you want to pick one yourself. | No |
| DCI Lite | A toggle for a lighter-weight connection class suited to non-critical applications like SAP or email services. | No |
| Rate Limit | The bandwidth for this connection. | Yes |
| Subscription Term | Short Term (1–11 months) or Long Term (12–60 months, "Better savings"). No PAYG — Layer 2 provisions over physical cross-connects. | Yes |

## 3. Add Ons

**Cross Connect** can be added at each end ("Managed by Lightstorm"), and **VISTA** — Standard (free) or Premium — layers on real-time monitoring, traffic analytics, and alerting across the connection.

![VISTA Standard and Premium add-on comparison for DCI Layer 2](/images/screenshots/dci-layer2/02-add-ons.jpg)

See [VISTA for Connections](/vista/connections) — DCI Layer 2 telemetry is covered under the same VISTA package as Cloud Connect connections.

## 4. Checkout

Review the **Order Summary**: it lists the A-End port and Z-End port separately — each with its **own billing profile** — followed by the Connection Details (name, bandwidth, term) with a third billing profile for the connection itself, plus VISTA if you added it.

![DCI Layer 2 checkout screen with per-end billing profiles](/images/screenshots/dci-layer2/03-checkout.jpg)

Click **Create DCI Layer 2** to place the order.

## After You Order

Track progress from the service's **Track Order** tab. Because Layer 2 rides over ports you already own, there's no new physical build — it typically moves from **Order Details Validated** to **Configured** to **Live** faster than a service that needs a new cross connect arranged.
