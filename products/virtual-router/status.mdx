After you order a Virtual Router, Polarin moves it through a small number of real statuses before it becomes operational. This page lists exactly what each one means, using the same status list you'll see in the Services page's own **Advance Filter** panel.

You can check the current status of any Virtual Router on the **Services** page. The status badge updates automatically as provisioning advances.

## Virtual Router Status Reference

![Advance Filter panel showing the full real status list: Live, Down, Design, Deployment in Progress, Configured, Deleted](/images/screenshots/services/06-advance-filter.jpg)

| Status | Description |
| --- | --- |
| **Design** | The router has been started but not fully ordered yet. A "Setup Incomplete" tag next to it means a required step in the wizard was never finished. |
| **Deployment in Progress** | The order has been submitted and the router instance is being provisioned. If your organisation requires a Purchase Order, a "Purchase Order Required" step appears here with a deadline. |
| **Configured** | The Virtual Router has been deployed and its configuration applied. Final activation is in progress — this status is specific to Virtual Router; Ports don't show it. |
| **Live** | The Virtual Router is fully operational. Connections can now be attached to it, and billing starts. |
| **Down** | The Virtual Router's network connectivity is currently down. Check BGP sessions and attached connections. |
| **Deleted** | The Virtual Router has been permanently removed and moved to Archived Services. |

<Info>
  **Ready to Patch** is also a real status, but it's Port-specific — a Virtual Router never shows it, since there's no physical cross-connect to patch in. See **Understand Port Status** for that one.
</Info>

## Normal Router Lifecycle

Under normal circumstances, a Virtual Router moves through the following progression after you place an order — matching the Track Order tab on the router's own detail page:

<Steps>
  <Step title="Order Details Validated">
    Your order information has been reviewed and approved.
  </Step>
  <Step title="Deployment in Progress">
    The router instance is being provisioned (Purchase Order Required step inserts here if your organisation issues POs).
  </Step>
  <Step title="Configured">
    Router deployed and configuration applied.
  </Step>
  <Step title="Live">
    Fully operational — connections can be attached, billing starts.
  </Step>
</Steps>

<Info>
  **Configured** means the software routing instance has been deployed and its parameters are applied. **Live** confirms it's actually ready to carry traffic.
</Info>

## Troubleshooting

### Router is stuck on "Deployment in Progress"

If there's an outstanding **Purchase Order Required** step on the Track Order tab, provisioning won't continue until PO details are added. Otherwise, if the status hasn't advanced after 24 hours, raise a support ticket with your Virtual Router's Service ID.

### Router shows "Down"

A **Down** status on a live router indicates a network connectivity issue. Check:

- BGP session state for all attached connections.
- Health of the underlying ports that carry traffic to this router.
- Whether there are any active incidents affecting the PoP.

If everything looks healthy on your side, open a support ticket with the router's Service ID and PoP location.
