Automate your network infrastructure through simple REST calls, no portal required. Provision services, monitor real-time performance, and integrate Polarin into your own automation workflows over standard HTTP.

<Tip>
  Available to active Polarin customers only. See [Getting Access](/api/getting-access) for the full sign-up-to-first-call journey.
</Tip>

## How It Works

<Steps>
  <Step title="Get Access">
    Register, complete KYC, and receive your API credentials. See [Getting Access](/api/getting-access).
  </Step>
  <Step title="Authenticate">
    Exchange your credentials for a short-lived JWT token, then pass it as the `access-token` header on every call.
  </Step>
  <Step title="Call the APIs">
    Use standard REST calls to provision ports, manage routers, monitor VISTA metrics, and more.
  </Step>
</Steps>

<Info>
  For the full reference with live request testing, open the [Developer Portal](/developer). It runs against a staging environment, so you can try real requests without touching live services or billing.
</Info>
